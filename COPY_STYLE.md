# QuestCraft copy style

One short guide so every screen sounds like the same game.

## Tone
Friendly, short and direct, like a teammate talking. Say what to do, not how you feel about it.
"Enter the 6-digit code we emailed you", not "Please Enter The Code Sent To Your Email".

## Casing
- **ALL CAPS (pixel font):** only short game titles: the logo, screen titles (SCHEDULE, LEADERBOARD),
  window titles (SETTINGS) and the one main action, START QUEST. At most 3 words.
- **Sentence case (Rajdhani):** everything else, including buttons, links, hints, messages and descriptions.
  Only the first word and names get a capital: "Create or switch hero", "Have a promo code?"
- Never Title Case Every Word.

## Icons
- Use the line icons in the sidebar (24×24 SVG, 1.8 stroke, `currentColor`). Add new ones in the same style.
- No emoji on buttons or labels. Emoji are fine inside chat messages and toasts, where they're part of the voice.

## One name per thing
| Use | Not |
|---|---|
| Hub | Home, Dashboard |
| Hero | Character, Profile |
| Sign in / Sign out | Log in, Login, Log out |
| Promo code | Coupon, Gift code (in player-facing text) |
| Timetable event | Event, Task (tasks are quest checklist items) |
| Buy 1 month | Subscribe, Pay |

## Actions
One primary button per screen (gold, big). Everything else is secondary (outline) or a text link.
Money actions (Buy, promo code) are never the primary action.
